<p align="center">
TrueFont replaces FFXI's lettering with fonts installed on your PC or loaded from its fonts folder. Set separate fonts for chat, menus, nameplates, damage numbers and more, while keeping the game's text layout and spacing.
</p>

## ![Install](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Install&letterSpacing=0.5px&weight=700)

Developed with **Ashita v4.3.2.1**, plugin interface **4.30**.

1. [Download latest release of TrueFont](https://github.com/SQLCommit/TrueFont/releases/latest). Choose the plugin ZIP whose `Interface-N.NN` matches your Ashita plugin interface; GitHub's source-code ZIP does not include the DLL.
2. Extract into `/ashita/`. The plugin should be at `/ashita/plugins/truefont.dll`.
3. In game, run `/load truefont`.
4. Once your character is in game, open `/truefont` and tick the **TrueFont** box at the top of a group's tab. Every tab starts off.

**Load automatically:** Add `/load truefont` to your startup script in `/ashita/scripts/`.


## ![Features](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Features&letterSpacing=0.5px&weight=700)

<details open>
<summary><strong>Eight font groups</strong> — Choose which parts of the game use your fonts.</summary>

<dl>
<dd>

| Tab | What it changes | Default look |
| :--- | :--- | :--- |
| **Chat/Items** | Chat, item names and descriptions, menu lists, help text and most game text | Semibold |
| **Labels** | Small menu labels, including Config, Delivery Box and the auction house's Category label | Bold |
| **Nameplates** | Names above players, monsters and NPCs | Bold, Italic |
| **HUD** | Party list, target bar, clock and other on-screen readouts | Bold, Italic |
| **Damage** | Floating damage and healing numbers; optional **Redraw "Miss!"** | Bold, Italic |
| **Headings** | Main menu commands, window headings and chat-mode tags | Bold, Italic |
| **Job Tags** | Job, level, race and nation labels | Bold |
| **Compass** | Compass directions | Bold, Italic |

Each group's **TrueFont** checkbox works independently. The sidebar's master switch controls TrueFont as a whole. Switching a group off keeps its settings and restores its original text.

</dd>
</dl>

</details>

---

<details>
<summary><strong>Font choices</strong> — Installed fonts, your own files and separate Japanese text.</summary>

<dl>
<dd>

- **Font:** Choose an installed font or one from TrueFont's fonts folder.
- **Same Font As:** Follow another group's font while keeping this group's own styling.
- **Japanese Font** (Chat/Items): Keep the original kana and kanji (**Off**, the default), use **Same as Font**, or choose a Japanese font. Characters missing from the chosen font keep their original appearance.

For fonts you do not want to install in Windows, put `.ttf`, `.otf`, `.ttc` or `.otc` files directly in `/ashita/config/truefont/fonts/`, then press **Rescan Fonts** or run `/tfont fonts rescan`. They are loaded only for the game. Subfolders are not scanned; unreadable files and files over 64 MB are skipped. An installed family takes priority over a folder copy.

Missing font families fall back to Segoe UI with a warning; the saved choice is kept. A missing Japanese font falls back to the Chat/Items font instead.

</dd>
</dl>

</details>

---

<details>
<summary><strong>Look</strong> — Adjust weight, brightness, outlines and shadows.</summary>

<dl>
<dd>

- **Chat/Items:** Regular, Semibold or Bold weight, plus **Brightness** from 0.6 to 1.6. Unsupported weights use the nearest available weight.
- **Other groups:** **Outline** can be Thin (default), Thick or Off, with an optional **Shadow**.
- **All groups:** **Italic** and **Faux Bold**. Faux Bold thickens thin lettering.
- **Damage:** Enable **Redraw "Miss!"** to replace that graphic too.

Chat/Items has no dark outline because of how FFXI blends that text. Use Faux Bold if it looks too thin. **Reset to Defaults** resets only the current tab.

</dd>
</dl>

</details>

---

<details>
<summary><strong>Sharpness and memory</strong> — Draw finer letters without changing their size.</summary>

<dl>
<dd>

Each group's **Sharpness** offers Auto, 2×, 3× or 4×.

| Group | Auto setting |
| :--- | :--- |
| **Chat/Items** | 16 px cells, or 32 px with FFXI's high-resolution font |
| **Nameplates / Damage** | Adapts to the window, rendering resolution, Aspect and Size; waits three seconds after a size change |
| **Other groups** | 2× |

Higher settings use more memory. TrueFont limits its font texture and rebuild budget to **160 MB**, reduces sharpness when needed, and shows unavailable choices in the panel. Chat/Items at 4× requires **Compress**; 4× with a Japanese Font exceeds the budget. On hardware that cannot use 3× textures, TrueFont uses 2×.

- **Compress** (Settings > Quality): Halves texture memory, with slightly softer edges. Off by default.
- **Keep Original** (Chat/Items > Detail): Keeps a copy of the game's chat font for rebuilding missing characters. On by default; turning it off saves 8 MB, or 16 MB with the high-resolution font, at the cost of slower rebuilds.

</dd>
</dl>

</details>

---

<details>
<summary><strong>Aspect and Size</strong> — Adjust nameplates and damage numbers, including their original fonts.</summary>

<dl>
<dd>

The Nameplates and Damage tabs each offer:

- **Aspect:** **Game** keeps FFXI's widescreen stretching; **4:3** restores its classic proportions; **True** uses the font's proportions.
- **Size:** 50% to 200%, in 10% steps. Default: 100%.

These controls work even with the group's replacement font off. Nameplate settings also affect the Job Mastery stars. The master switch and **Show Original** restore the game's proportions too.

**Nameplate** takes priority over TrueFont's Nameplate Aspect and Size controls while loaded. **dmgnum** Native mode combines with TrueFont's Damage settings; its Custom mode takes priority. Unavailable or conflicting controls are disabled with a note in the panel.

**Game code change.** Aspect and Size are TrueFont's only change to game code. The game sizes these letters with one number that each draw reads twice; TrueFont redirects those two 4-byte reads, at the names, the star row and the damage numbers, to values in a small memory page of its own. It writes only where the game's own code is still in place, never over another plugin's bytes. Nothing is written at Game and 100%, and the game's code is put back when you return to Game and 100%, switch TrueFont off, or unload it. If TrueFont is unloaded while Nameplate is still loaded, that page stays, holding the game's own values, until the game closes, because Nameplate's own unload points the game back at it.

</dd>
</dl>

</details>

<details>
<summary><strong>Rendering engine</strong> — Choose Windows, FreeType or Auto.</summary>

<dl>
<dd>

**Settings > Quality > Engine** controls how letters are drawn:

| Engine | When to use it |
| :--- | :--- |
| **Windows** (default) | Crisp small text with most TrueType fonts |
| **FreeType** | Preserves the shapes of PostScript-style OpenType fonts, such as FOT-Rodin |
| **Auto** | Uses FreeType for PostScript-style fonts and under Wine; Windows otherwise |

**Hinting** snaps letters to the pixel grid for sharper small text. It is on by default; turn it off for softer, less adjusted shapes. Changing Engine, Hinting or Compress rebuilds the fonts.

FreeType is built in. If it cannot draw a font, TrueFont falls back to Windows and records the reason in the log; if you chose FreeType, chat also says so once. `/tfont diag` reports which engine each group used.

</dd>
</dl>

</details>

---

<details>
<summary><strong>Presets and Every Character</strong> — Save named looks or share settings across characters.</summary>

<dl>
<dd>

In **Settings > Presets**, use **Save As** to save a look (names up to 40 characters, about 13 in Japanese), **Load** to apply it, or **Delete** to remove it. Saving an existing name replaces it; deletion needs a second click. Presets are available to all characters and do not change the master on/off switch.

**Every Character** shares font settings with other characters that enable it. Turning it on copies this character's settings to the shared file; turning it off saves the current settings to this character. Each character keeps its own master on/off setting. Changes to different settings from separate game windows are saved independently.

**Reset All** restores every tab's defaults, leaving TrueFont's master switch, presets and Every Character unchanged.

</dd>
</dl>

</details>

---

<details>
<summary><strong>Status and Compare</strong> — Check active groups, memory use and the original appearance.</summary>

<dl>
<dd>

The sidebar shows the client language, active font groups, build progress and memory use. **From Font** counts replaced characters; **Native** counts those keeping the original art. **Re-Applied** counts textures restored after something else replaced them.

**Show Original** temporarily restores the original fonts, Aspect and Size for comparison without rebuilding. With a compatible font mod installed, this shows the mod's art.

</dd>
</dl>

</details>

<details>
<summary><strong>Compatibility</strong> — Font mods and supported game languages.</summary>

<dl>
<dd>

**XiView** and **Pivot** font overlays work when they preserve the game's layout. Icons, logos and disabled groups keep the mod's art; unrecognized layouts are left unchanged. After changing a mod during play, run `/tfont on` to check its textures again. HorizonXI's font layout is recognized, but compatibility has not yet been confirmed in play.

| Client language | Support |
| :--- | :--- |
| **English** | All groups |
| **Japanese** | All groups implemented; not yet confirmed in play. Japanese Font controls chat kana and kanji |
| **German / French** | Chat/Items, plus Nameplate and Damage Aspect/Size. Other fonts remain original |

</dd>
</dl>

</details>

## ![Commands](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Commands&letterSpacing=0.5px&weight=700)

| Command | Action |
| :--- | :--- |
| `/truefont` | Show or hide settings |
| `/tfont on` / `/tfont off` | Enable or disable TrueFont; `on` also retries unavailable textures |
| `/tfont font "<family>"` | Set the Chat/Items font; omit the name to show the current choice |
| `/tfont fonts` | Show installed and folder font counts |
| `/tfont fonts rescan` | Refresh the font list and reload the fonts folder |
| `/tfont rebuild` | Rebuild with the current settings |
| `/tfont original [on\|off]` | Toggle or set Show Original |
| `/tfont reset` | Reset all groups and quality settings; keep the master switch unchanged |
| `/tfont status` | Show current fonts and settings file |
| `/tfont diag` | Write a diagnostic report to the log |

`/truefont` and `/tfont` are interchangeable prefixes. Font names are case-insensitive; quotes are optional.

## ![Settings and logs](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Settings+and+logs&letterSpacing=0.5px&weight=700)

| Files | Location |
| :--- | :--- |
| **Character settings** | `/ashita/config/truefont/<Name>_<id>/settings.ini` |
| **Shared settings** | `/ashita/config/truefont/shared/settings.ini` |
| **Presets** | `/ashita/config/truefont/presets/<name>.ini` |
| **Fonts folder** | `/ashita/config/truefont/fonts/` |
| **Character log** | `/ashita/logs/truefont/<Name>_<id>/truefont.log` |

Before login, logs use `/ashita/logs/truefont/startup_*.log`. Settings load per character; an unreadable file uses defaults and is left untouched.

<details>
<summary><strong>Settings file keys</strong> — The keys in the `[truefont]` section of `settings.ini`.</summary>

<dl>
<dd>

- **General:** `enabled` (1 or 0), `defaults` (2; a missing key then takes the new-player default), `engine` (`windows`, `freetype` or `auto`), `hinting`, `compress`, `keep_original`, `miss_redraw`, `share_all` (Every Character).
- **Per group**, where `<group>` is `chat`, `labels`, `plates`, `names` (HUD), `damage`, `headings`, `jobs` or `compass`: `<group>_on`, `<group>_same` (Same Font As), `<group>_follow` (the group it follows), `<group>_font` (absent: the first font), `<group>_weight` (400, 600 or 700), `<group>_faux_bold`, `<group>_italic`, `<group>_sharp` (`auto`, `2`, `3` or `4`).
- **All groups but Chat/Items:** `<group>_outline` (`off`, `thin` or `thick`) and `<group>_shadow`.
- **Chat/Items:** `chat_gamma` (Brightness, 0.6 to 1.6) and `chat_jp` (`off`, `same` or a family).
- **Nameplates and Damage:** `plates_aspect` and `damage_aspect` (`game`, `4:3` or `true`), `plates_size` and `damage_size` (50 to 200, in steps of 10).

Presets use the same keys without `enabled` and `share_all`. An invalid value takes that group's default. A save writes only the keys that changed.

</dd>
</dl>

</details>

**Backup:** Copy `/ashita/config/truefont/`. Run `/tfont diag` and include the log when [reporting a problem](https://github.com/SQLCommit/TrueFont/issues).
